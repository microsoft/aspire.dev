## Name

`aspire config set` - Set a configuration value.

## Synopsis

```bash title="Aspire CLI"
aspire config set <key> <value> [options]
```

## Description

The `aspire config set` command sets a config value by key name.

<Include relativePath="reference/cli/includes/config-file-description.md" />

## Arguments

The following arguments are available:

- **`key`**

  The configuration key to set. Use dots for nested properties and `[index]` to create or edit array elements.

- **`value`**

  The configuration value to set.

## Array values

Use bracket syntax with a zero-based index to create or edit array elements. Quote keys that contain brackets so the shell passes them to the CLI.

For example, consider this illustrative `plugins` array:

```json title="aspire.config.json"
{
  "plugins": ["aspire", "other"]
}
```

The following command changes the first element to `deployment`:

```bash title="Aspire CLI"
aspire config set "plugins[0]" deployment
```

The resulting array is `["deployment", "other"]`. To append a new element, set the next index:

```bash title="Aspire CLI"
aspire config set "plugins[2]" monitoring
```

If the array doesn't exist, setting index `0` creates it. For an existing array, numeric dotted segments also select an array element:

```bash title="Aspire CLI"
aspire config set plugins.0 deployment
```

Numeric dotted segments that don't refer to an existing array remain object property names. Negative indexes, gaps in the array, malformed bracket paths, and bracketed array edits against objects or scalar values fail without writing the configuration file.

## Options

The following options are available:

- **`-g, --global`**

  Set the configuration value in user-scoped global Aspire configuration
  instead of the rooted `aspire.config.json` file.
  Project-specific values such as `appHost.path` can't be set globally.
