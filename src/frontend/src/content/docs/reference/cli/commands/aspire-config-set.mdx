## Name

`aspire config set` - Set a configuration value.

## Synopsis

```bash title="Aspire CLI"
aspire config set <key> <value> [options]
```

## Description

The `aspire config set` command sets a config value by key name.

<Include relativePath="reference/cli/includes/config-file-description.md" />

## Arguments

The following arguments are available:

- **`key`**

  The configuration key to set. Use dots for nested properties and `[index]` to create or edit array elements.

- **`value`**

  The configuration value to set.

## Array values

Use bracket syntax to create or edit array elements. Setting the next index appends an element, and other array elements are preserved:

```bash title="Aspire CLI"
aspire config set "skillSources.team.plugins[0]" deployment
```

For an existing array, numeric dotted segments also edit the array element:

```bash title="Aspire CLI"
aspire config set skillSources.team.plugins.0 deployment
```

Numeric dotted segments that don't refer to an existing array remain object property names. Negative indexes, gaps in the array, malformed bracket paths, and array edits against objects or scalar values fail without writing the configuration file.

The `aspire config get` and `aspire config delete` commands accept the same bracket paths. Deleting an array element compacts the remaining indexes, and `aspire config list` shows array entries with bracketed indexes, such as `plugins[0]`.

## Options

The following options are available:

- **`-g, --global`**

  Set the configuration value in user-scoped global Aspire configuration
  instead of the rooted `aspire.config.json` file.
  Project-specific values such as `appHost.path` can't be set globally.
