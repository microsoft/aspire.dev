## Name

`aspire template source add` - Add a named template source to global configuration after confirming you trust it.

## Synopsis

```bash title="Aspire CLI"
aspire template source add <name> [options]
```

## Description

The `aspire template source add` command adds a named template source to global Aspire configuration. A template source is identified by a repository URL (`--repository`) or a local path (`--path`).

Templates can run code, so the command asks you to trust the source before it changes any configuration. The prompt shows the source name and its repository URL or local path, and defaults to **No**:

```text
Templates can run code. Do you trust template source 'company' (https://example.com/templates)? [y/N]:
```

If you decline, the command is canceled and configuration isn't changed. To trust the source and skip the prompt, pass `--yes`.

Non-interactive invocations, including invocations where interactive input isn't available, fail unless you pass `--yes`.

## Arguments

The following arguments are available:

- **`name`**

  The name of the template source.

## Options

The following options are available:

- **`--path`**

  The local path of the template source.

- **`--repository`**

  The repository URL of the template source.

- **`--ref`**

  The Git reference of the template source repository.

- **`-y, --yes`**

  Trust the template source and skip confirmation.

## Examples

- Add a template source and confirm trust interactively:

  ```bash title="Aspire CLI"
  aspire template source add company --repository https://example.com/templates
  ```

- Add a template source in automation by explicitly trusting it:

  ```bash title="Aspire CLI"
  aspire template source add company --repository https://example.com/templates --non-interactive --yes
  ```
