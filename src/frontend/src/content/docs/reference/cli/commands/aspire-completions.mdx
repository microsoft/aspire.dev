## Name

`aspire completions` - Generate shell completion scripts.

## Synopsis

```bash title="Aspire CLI"
aspire completions [command] [options]
```

## Description

The `aspire completions` command generates shell completion scripts for the Aspire CLI. Source a generated script in your shell to complete `aspire` commands, subcommands, options, and values with <kbd>Tab</kbd>.

For setup, removal, and troubleshooting steps for each shell, see [Shell completion](/reference/cli/shell-completion/).

## Examples

- Enable completion in the current Bash shell:

  ```bash title="Bash"
  source <(aspire completions script bash)
  ```
