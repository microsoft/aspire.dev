## Name

`aspire tray` - Manage the desktop tray companion (Experimental).

## Synopsis

```bash title="Aspire CLI"
aspire tray [command] [options]
```

## Description

The `aspire tray` command manages the experimental Aspire tray companion, a desktop panel icon for managing local AppHosts. The tray is available on Windows, macOS, and glibc Linux (x64 and ARM64). The command is hidden from help on unsupported operating systems and on musl-based Linux.

<Aside type="caution">
  The tray companion is experimental. It requires a native Aspire CLI installation with a bundle that includes the tray companion. Managed development builds and `dotnet aspire.dll` aren't supported.
</Aside>

## Linux requirements

On Linux, the tray renders a StatusNotifierItem and D-Bus menu through the desktop's tray host. The following are host dependencies and aren't bundled with the CLI:

- A graphical, tray-capable desktop session. Headless sessions and musl-based distributions aren't supported.
- GTK 3.
- An AppIndicator library, such as Ayatana AppIndicator or a compatible libappindicator.
- A tray host: GNOME needs an AppIndicator extension, and Waybar needs its tray module.

If no tray host is available when you run `aspire tray start`, the CLI reports it. The icon appears as soon as tray support becomes available.
