## Name

`aspire template source list` - List named template sources without discovering templates.

## Synopsis

```bash title="Aspire CLI"
aspire template source list [options]
```

## Description

The `aspire template source list` command lists the template sources in global Aspire configuration, sorted by name. It reads only configuration: it doesn't contact repositories or discover templates. Incomplete source definitions are included so that you can inspect and fix them.

By default, the command shows a table with each source name and its configured fields. If no sources are configured, the command says so and suggests [`aspire template source add`](../aspire-template-source-add/).

## Options

The following options are available:

- **`--format <Json|Table>`**

  The output format. The default is `Table`. `Json` writes an object keyed by source name to standard output, preserving the configured fields without adding defaults.

## Examples

- List template sources as a table:

  ```bash title="Aspire CLI"
  aspire template source list
  ```

- List template sources as JSON:

  ```bash title="Aspire CLI"
  aspire template source list --format Json
  ```
