## Name

`aspire template` - Manage project templates.

## Synopsis

```bash title="Aspire CLI"
aspire template [command] [options]
```

## Description

The `aspire template` command manages template configuration for the Aspire CLI. It contains the `source` command group, which manages the global template sources that [`aspire new`](../aspire-new/#select-a-template) uses to discover templates.
