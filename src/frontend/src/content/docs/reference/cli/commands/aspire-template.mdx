## Name

`aspire template` - Manage templates.

## Synopsis

```bash title="Aspire CLI"
aspire template [command] [options]
```

## Description

The `aspire template` command manages template configuration for the Aspire CLI. Currently, it contains the `source` command group, which manages global template sources used by [`aspire new`](../aspire-new/).
