## Name

`aspire terminal tape` - Automate existing resource terminal sessions with tape files.

## Synopsis

```bash title="Aspire CLI"
aspire terminal tape [command] [options]
```

## Description

The `aspire terminal tape` command group runs scripted terminal interactions against resources registered with [`WithTerminal()`](/app-host/with-terminal/). Its `play` subcommand sends input, waits for output, and can record text screens without launching a new shell or owning the resource lifecycle.

:::caution[Experimental in Aspire 13.6]
Tape playback requires Aspire CLI 13.6 or later and an AppHost with terminal support. The command group is hidden unless the terminal feature flag is enabled:

```bash title="Enable terminal commands"
aspire config set features.terminalCommandsEnabled true
```

:::

For runnable shell and REPL examples and the supported [Tape file syntax](/dashboard/terminal-tape-playback/#tape-file-syntax), see [Automate resource terminals with tape files](/dashboard/terminal-tape-playback/).
