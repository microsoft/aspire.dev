## Name

`aspire tray start` - Start or restore the tray icon.

## Synopsis

```bash title="Aspire CLI"
aspire tray start [options]
```

## Description

The `aspire tray start` command starts the experimental tray companion, or restores its icon if the companion is already running.

The first `aspire tray start` extracts the bundled companion payload and launches it. A subsequent `aspire tray start` restores the existing tray icon without starting another watcher process. Startup is acknowledged by the native UI loop before the command returns.

:::caution[Experimental]
`aspire tray start` is experimental and supports only macOS and Windows (x64 and ARM64). See [`aspire tray`](../aspire-tray/) for the full list of outstanding validation before this feature ships as stable.
:::

If you start the tray companion from a different CLI installation than the one currently running it, that newer CLI's invocation becomes the running companion's backend. Stop and start again to have the tray adopt a new CLI or bundle.
