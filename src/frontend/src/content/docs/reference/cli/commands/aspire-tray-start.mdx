## Name

`aspire tray start` - Start or restore the tray icon (Experimental).

## Synopsis

```bash title="Aspire CLI"
aspire tray start [options]
```

## Description

The `aspire tray start` command starts the Aspire tray companion, or restores its icon if it's already running. The tray discovers local AppHosts, shows their health, and lets you stop an exact instance, open the dashboard, start AppHosts, manage pins and history, and change settings. On Linux, the menu also provides folder, copy-path, and VS Code actions, and an opt-in XDG login startup setting.

Menus show colored health dots for resources and a gray square for stopped projects. AppHosts with no visible resources show "No resources" rather than an unknown health state. Some GNOME AppIndicator versions suppress icons on submenu headers, so health text is retained.

The command requires a native CLI bundle that includes the tray companion. For platform requirements, see [aspire tray](../aspire-tray/).

<Aside type="note">
  The command doesn't change desktop configuration or register login startup automatically.
</Aside>
