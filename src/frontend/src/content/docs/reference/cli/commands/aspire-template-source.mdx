## Name

`aspire template source` - Manage global template sources.

## Synopsis

```bash title="Aspire CLI"
aspire template source [command] [options]
```

## Description

The `aspire template source` command manages global template sources. A template source is a named location that contains templates: either a Git repository or an absolute local directory. Sources are stored in the global Aspire configuration, so they apply to every project on the machine.

When at least one source is configured, the interactive [`aspire new`](../aspire-new/#select-a-template) template picker lists templates from each source alongside the built-in templates. If a configured source can't be read when `aspire new` discovers templates, the command warns about that source and continues with the others.

Template sources require the `aspire.config.json` configuration format. If your global configuration still uses the legacy format, these commands fail and direct you to run `aspire config info` to migrate it.

## Commands

The following commands are available:

| Command                                                                   | Function                                                   |
| ------------------------------------------------------------------------- | ---------------------------------------------------------- |
| [`aspire template source add <name>`](../aspire-template-source-add/)     | Add a named template source after confirming you trust it. |
| [`aspire template source list`](../aspire-template-source-list/)          | List the configured template sources.                      |
| [`aspire template source remove <name>`](../aspire-template-source-remove/) | Remove a named template source.                          |

## Examples

- Add a template source from a Git repository:

  ```bash title="Aspire CLI"
  aspire template source add company --repository https://github.com/example/templates
  ```

- List the configured template sources:

  ```bash title="Aspire CLI"
  aspire template source list
  ```

- Remove a template source:

  ```bash title="Aspire CLI"
  aspire template source remove company
  ```
