## Name

`aspire tray stop` - Stop the tray without stopping AppHosts.

## Synopsis

```bash title="Aspire CLI"
aspire tray stop [options]
```

## Description

The `aspire tray stop` command stops the Aspire tray companion. Running AppHosts aren't stopped. On Linux, any open tray dialogs are canceled without confirming actions or saving settings.
