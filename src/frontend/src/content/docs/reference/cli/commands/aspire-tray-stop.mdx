## Name

`aspire tray stop` - Stop the tray without stopping AppHosts.

## Synopsis

```bash title="Aspire CLI"
aspire tray stop [options]
```

## Description

The `aspire tray stop` command stops the experimental tray companion and its discovery child process. It doesn't stop any AppHosts that the tray was tracking — use [`aspire stop`](../aspire-stop/) or the tray's own **Stop** menu action for that.

Choosing **Quit Aspire** from the tray's menu has the same effect as running `aspire tray stop`.

:::caution[Experimental]
`aspire tray stop` is experimental. See [`aspire tray`](../aspire-tray/) for the full list of outstanding validation before this feature ships as stable.
:::
