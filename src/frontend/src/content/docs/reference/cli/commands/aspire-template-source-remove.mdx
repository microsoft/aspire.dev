## Name

`aspire template source remove` - Remove a named template source from global configuration.

## Synopsis

```bash title="Aspire CLI"
aspire template source remove <name> [options]
```

## Description

The `aspire template source remove` command removes a named template source from global Aspire configuration. Templates from the removed source no longer appear in the [`aspire new`](../aspire-new/#select-a-template) template picker. The command fails if no template source with the given name exists.

## Arguments

The following arguments are available:

- **`name`**

  The name of the template source to remove. Names are case-insensitive.
