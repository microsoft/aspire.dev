> Kubernetes persistent volume APIs are for evaluation purposes only and are subject to change or removal in future updates. Suppress this diagnostic to proceed.

This diagnostic warning is reported when using the experimental Kubernetes persistent volume APIs: `KubernetesPersistentVolumeExtensions`, `KubernetesPersistentVolumeResource`, `PersistentVolumeAccessMode`, and `AzureKubernetesPersistentVolumeExtensions`.

<Aside type="note">
Starting in Aspire 17.0, the compute environment endpoint-mapping contracts `IComputeEnvironmentResource.GetHostAddressExpression` and `IComputeEnvironmentResource.GetEndpointPropertyExpression` are stable and no longer report `ASPIRECOMPUTE002`. You can remove suppressions that were added only for those members. Suppressions for persistent volume APIs are still required.
</Aside>

## Endpoint-mapping contracts

`GetHostAddressExpression` returns a `ReferenceExpression` for the host only, without scheme, port, or path. It isn't a full URL. `GetEndpointPropertyExpression` composes the host, scheme, and port expressions by default, and compute environments can override it with platform-specific mappings.

The default `GetHostAddressExpression` implementation throws `NotImplementedException`, so environments that don't provide host mapping (for example, `AzureKubernetesEnvironmentResource`) still inherit that behavior.

```csharp title="No suppression required"
var builder = DistributedApplication.CreateBuilder(args);

var environment = builder.AddDockerComposeEnvironment("env");
var api = builder.AddContainer("api", "nginx")
    .WithHttpEndpoint(targetPort: 80);

IComputeEnvironmentResource compute = environment.Resource;
var endpoint = api.GetEndpoint("http");
ReferenceExpression host = compute.GetHostAddressExpression(endpoint);
ReferenceExpression url = compute.GetEndpointPropertyExpression(
    endpoint.Property(EndpointProperty.Url));
```

## To suppress this warning

Suppress the warning with either of the following methods:

- Set the severity of the rule in the _.editorconfig_ file.

  ```ini title=".editorconfig"
  [*.{cs,vb}]
  dotnet_diagnostic.ASPIRECOMPUTE002.severity = none
  ```

  For more information about editor config files, see [Configuration files for code analysis rules](/diagnostics/overview/#suppress-in-the-editorconfig-file).

- Add the following `PropertyGroup` to your project file:

  ```xml title="C# project file"
  <PropertyGroup>
      <NoWarn>$(NoWarn);ASPIRECOMPUTE002</NoWarn>
  </PropertyGroup>
  ```

- Suppress in code with the `#pragma warning disable ASPIRECOMPUTE002` directive:

  ```csharp title="Suppressing the warning"
  #pragma warning disable ASPIRECOMPUTE002
  var k8s = builder.AddKubernetesEnvironment("k8s");
  var data = k8s.AddPersistentVolume("data")
      .WithAccessMode(PersistentVolumeAccessMode.ReadWriteOnce);
  #pragma warning restore ASPIRECOMPUTE002
  ```
