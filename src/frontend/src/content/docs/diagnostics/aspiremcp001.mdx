`ASPIREMCP001` was emitted by earlier versions of Aspire when code called the experimental <ApiReference name="Aspire.Hosting.McpServerResourceBuilderExtensions.WithMcpServer" /> extension method, which declares an <abbr title="Model Context Protocol" data-tooltip-placement="top">MCP</abbr> server exposed by a resource so Aspire tooling can discover and proxy it. This diagnostic no longer applies in Aspire 17.0 and later because `WithMcpServer` is stable, and no other API reports it.

## If you still see this warning

Upgrade the Aspire CLI, AppHost SDK, and hosting integration packages to Aspire 17.0 or later. After upgrading, remove any `ASPIREMCP001` suppressions from _.editorconfig_ files, project files, and `#pragma warning` blocks.

The PostgreSQL MCP integration, <ApiReference name="Aspire.Hosting.PostgresBuilderExtensions.WithPostgresMcp" />, is still experimental and reports [`ASPIREPOSTGRES001`](/diagnostics/aspirepostgres001/) instead.

  For more information, see [Resource MCP servers](/get-started/resource-mcp-servers/).
</LearnMore>
