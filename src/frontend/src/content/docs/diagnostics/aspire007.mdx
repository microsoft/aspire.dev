> The project is missing a required Aspire.AppHost.Sdk with a version of at least 9.0.0. Please add the following line after the Project declaration `<Sdk Name="Aspire.AppHost.Sdk" Version="9.0.0" />`.

This diagnostic applies to the SDK requirement introduced with Aspire 9.0. With those package versions, the SDK reference is either omitted or uses a version older than 9.0.0. Aspire 17.0 still reports it for retained SDKs older than 9.0.0 or an invalid retained SDK reference. The legacy correction below is for SDK-based projects.

Starting in Aspire 17.0, package-based AppHosts no longer require `Aspire.AppHost.Sdk`. Use `Microsoft.NET.Sdk` with explicit AppHost and Dotnet packages instead; see [Migrate from the AppHost SDK](/get-started/migrate-apphost-sdk/). Don't reintroduce the obsolete SDK into a package-based 17.0 AppHost to follow the legacy example.

## To correct this error

Update the referenced SDK version to 9.0.0 or the latest.

If the SDK reference is missing from your project file, add it, as demonstrated in the following snippet:

```xml title="C# project file"
<Project Sdk="Microsoft.NET.Sdk">

  <Sdk Name="Aspire.AppHost.Sdk" Version="9.0.0" />

  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net9.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
    <IsAspireHost>true</IsAspireHost>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="Aspire.Hosting.AppHost" Version="9.2.0" />
  </ItemGroup>

</Project>
```
