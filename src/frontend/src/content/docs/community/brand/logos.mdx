The SVG files scale without losing detail. Preserve the artwork's proportions and fill colors, and read the [usage guidance](/community/brand/usage/) before adapting a mark.

## Logos

Choose a horizontal or stacked layout for the space available. **Dark** and **light** refer to the lettering: use dark lettering on light backgrounds and light lettering on dark backgrounds.

Each preview uses a background that contrasts with the lettering. Leave space around the logo and keep it clear of partner marks and dense UI.

<BrandAssetGallery
  assets={brandAssets.filter((asset) => asset.kind === 'logo')}
/>

The wordmark SVGs include outlined lettering, so they do not require installed fonts. Each preview shows the file you download.

## Developer icons

Use these official derivatives to identify Aspire in developer icon libraries, documentation and README badges, editors, terminals, and other developer tools.

All three use a `0 0 128 128` viewBox. The line and plain variants each use a single filled path without strokes.

<BrandAssetGallery
  assets={brandAssets.filter((asset) => asset.kind === 'developer')}
/>

Proportional resizing, monochrome rendering or recoloring, and SVG optimization or path normalization are permitted for these developer-icon uses when the recognizable Aspire shape and proportions are preserved. This exception does not apply to ordinary logos or arbitrary redesigns.

See the [developer-icon usage permission](/community/brand/usage/#developer-icon-permission) for the scope of this permission and its trademark limitations.
