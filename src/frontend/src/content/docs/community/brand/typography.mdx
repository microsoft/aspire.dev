**Poppins** is the Aspire brand typeface. Use it for headings, interface text, and supporting brand copy.

## Font weights

The specimens show regular 400, medium 500, semibold 600, and bold 700. aspire.dev hosts these Poppins font weights locally.

<BrandTypography />

## Get the typeface

Get the font files and available styles from <BrandExternalLink href="https://fonts.google.com/specimen/Poppins">Poppins at Google Fonts</BrandExternalLink>.

For local hosting on a website, use <BrandExternalLink href="https://fontsource.org/fonts/poppins">Fontsource Poppins</BrandExternalLink>.

## Code font

aspire.dev uses **Fira Code Variable** for code blocks, inline code, and other monospaced text. The font is hosted locally, with regular 400 used for code blocks.

<BrandCodeTypography />

Find the font files and installation options at <BrandExternalLink href="https://fontsource.org/fonts/fira-code">Fontsource Fira Code Variable</BrandExternalLink> or the <BrandExternalLink href="https://github.com/tonsky/FiraCode">Fira Code repository</BrandExternalLink>.
