The Deno support in `Aspire.Hosting.JavaScript` adds Deno apps to your [AppHost](/get-started/app-host/). Aspire starts the Deno process locally, shows it in the dashboard, and lets you connect it to the rest of your distributed application.

<Aside type="caution">
  The Deno APIs are experimental and report the `ASPIREDENO001` diagnostic.
</Aside>

## How the integration works

The integration is a hosting integration: install `Aspire.Hosting.JavaScript` in the AppHost, then model each application with an <ApiReference name="Aspire.Hosting.JavaScriptHostingExtensions.AddDenoApp" /> resource. The resource runs the local `deno` command. You configure its permissions, runtime flags, arguments, endpoints, environment variables, and health checks in the AppHost.

By default the resource runs a script with `deno run`. Call <ApiReference name="Aspire.Hosting.JavaScriptHostingExtensions.WithDenoTask" /> to run a task from `deno.json` or `deno.jsonc` with `deno task`, or <ApiReference name="Aspire.Hosting.JavaScriptHostingExtensions.WithDenoServe" /> to use `deno serve`. Deno resources participate in service discovery and can be referenced by other resources.

## Prerequisites

- Install [Deno](https://docs.deno.com/runtime/getting_started/installation/) and ensure `deno` is available on your `PATH`.
- Install the [Aspire CLI](/get-started/install-cli/) and meet the [Aspire prerequisites](/get-started/prerequisites/).
- Create an AppHost in C# or TypeScript.

## Add a Deno resource

Add the `Aspire.Hosting.JavaScript` package to your AppHost. Then add a Deno app resource:

<Tabs syncKey='aspire-lang'>
<TabItem id='csharp' label='C#'>

```csharp title="AppHost.cs"
using Aspire.Hosting.JavaScript;

var builder = DistributedApplication.CreateBuilder(args);

#pragma warning disable ASPIREDENO001
var app = builder.AddDenoApp("web", "../web", "main.ts")
    .WithDenoTask("dev")
    .WithHttpEndpoint(env: "PORT")
    .WithHttpHealthCheck("/");
#pragma warning restore ASPIREDENO001

builder.Build().Run();
```

</TabItem>
<TabItem id='typescript' label='TypeScript'>

```typescript title="apphost.mts"
import { createBuilder } from './.aspire/modules/aspire.mjs';

const builder = await createBuilder();

const app = await builder
  .addDenoApp('web', '../web', 'main.ts')
  .withDenoTask('dev')
  .withHttpEndpoint({ env: 'PORT' })
  .withHttpHealthCheck({ path: '/' });

await builder.build().run();
```

</TabItem>
</Tabs>

Have the Deno application listen on the endpoint environment variable. For example, grant the `--allow-env` permission when an application reads `PORT`.
