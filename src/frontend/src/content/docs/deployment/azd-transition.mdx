title: Transition Aspire AppHost deployments from azd
description: Guidance for Aspire AppHost users transitioning from Azure Developer CLI to aspire deploy, with details pending collaboration with the AZD team.
---

If you deploy Aspire AppHosts with Azure Developer CLI (`azd`), we recommend transitioning to `aspire deploy`.

:::note[Transition guidance is being prepared]
This page is a placeholder. Transition details and messaging are pending collaboration with the Azure Developer CLI team.
:::

This recommendation is specific to deploying Aspire AppHosts. Azure Developer CLI itself and the `azd up`, `azd provision`, and `azd deploy` commands are not being retired.
